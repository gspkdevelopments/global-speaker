# i18n v2 implementation status

Status: implementation in progress on isolated feature branch.

Goal: full EN/ES/FR website availability with interface locale independent from target learning language.

## Curriculum localization pilot

The first Spanish-interface → French-target foundation route now uses a reviewed localized-content overlay across eight connected lessons. Supporting explanations, instructions, practice feedback, and progress evidence are Spanish; target phrases and learner production remain French. The route covers identity, personality, urgent needs, and leisure/interests. Canonical corpus content remains the fallback for locale/lesson pairs that have not yet been reviewed.
